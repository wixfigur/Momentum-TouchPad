# Momentum TouchPad
Brings back the trackball-like cursor momentum (inertia) to modern Windows laptops with Precision Touchpad

## The Problem
Older laptops with dedicated Synaptics drivers and software had a fantastic feature: when you flicked your finger and let go, the mouse cursor kept gliding smoothly and slowly slowed down (inertia/momentum).
Modern laptops completely rely on native Windows Precision Touchpad drivers, that completely removed this fluid momentum cursor move

## Features
* **Fluid Cursor Momentum:** Mimics the classic Synaptics Momentum feel.
* **Lightweight & Fast:** Runs quietly in the background with almost no CPU usage.

## Installation & Usage
Download and run MomentumTouchPad.exe from the **Releases** section

## Configuration
Click MomentumTouchPad.exe (or start menu shortcut) once, the program starts and runs completly in background. Click it once more, the settings menu opens.
